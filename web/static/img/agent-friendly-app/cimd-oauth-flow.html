OAuth 2.1 + PKCE, with a Client ID Metadata Document (CIMD)

How an MCP client logs in to Linkly

You ran claude mcp add --transport http linkly https://myapp.com/mcp and clicked Allow. Here's everything that happened, one message at a time. Most of it is standard OAuth. The steps marked CIMD are the part that lets any client connect without registering first. Watch the "What each one knows" row: it shows where the secrets, the one-time code, and the tokens are after every step.
