# @wasp/wasp API docs

Docs-only package that TypeDoc uses to generate the API reference of the modules of `@wasp/wasp` that users import, published at https://wasp.sh/docs/api/@wasp/wasp.

`types/` has hand-written `.d.ts` files, one per import path: `types/vite.d.ts` documents `@wasp/wasp/vite`. Keep them in sync with what `packages/wasp/lib/` exports.

> [!NOTE]
> The user-facing intro of the API reference is in [`docs.md`](./docs.md).
