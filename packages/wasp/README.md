# Wasp

The fastest way to develop full-stack web apps with React & Node.js.

Your Wasp app depends on this package. Its version sets the Wasp version your app runs, and it brings the Wasp CLI and the Wasp Spec at that version.

## Create your first app

```sh
npx @wasp/cli@latest new
cd <my-project-name>
npm run dev
```
