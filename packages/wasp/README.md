# Wasp

The fastest way to develop full-stack web apps with React & Node.js.

Wasp is a Rails-like framework for React, Node.js and Prisma. You describe your app's pages, routes, auth and operations in `main.wasp.ts`, and write the rest in plain React and Node.js. Wasp connects it all: full-stack auth, type-safe calls from the client to the server, background jobs, email, and deployment with a single command.

This is the package your Wasp app depends on. Its version is the Wasp version your app runs.

## Get started

```sh
npx @wasp/cli@latest new
cd <my-project-name>
npm run dev
```
